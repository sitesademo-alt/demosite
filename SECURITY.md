# Security policy

This repository is **intentionally vulnerable**. It exists solely to test and
demonstrate security-scanning and dependency auto-remediation tooling in a
controlled, local environment.

- Do **not** deploy it or expose it to any network.
- Do **not** copy its dependency versions into real projects.
- The known-vulnerable versions listed in `README.md` are here by design; please
  do not file reports for them.

If you find a problem unrelated to the intentional vulnerabilities (for example,
the build scaffolding or docs), feel free to open an issue.
